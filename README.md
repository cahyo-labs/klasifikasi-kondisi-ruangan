# Klasifikasi Kondisi Ruangan Menggunakan Decision Tree

## Deskripsi
Proyek ini merupakan implementasi Machine Learning untuk mengklasifikasikan kondisi ruangan berdasarkan suhu, kelembapan relatif, dan intensitas cahaya.

## Tujuan
1. Melakukan preprocessing dataset sensor.
2. Membangun model klasifikasi baseline menggunakan Decision Tree.
3. Mengevaluasi model menggunakan accuracy, precision, recall, F1-score, dan confusion matrix.
4. Menyediakan pipeline yang dapat dikembangkan menggunakan data sensor aktual.

## Teknologi
- Python
- Pandas dan NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Dataset
Dataset yang digunakan merupakan dataset simulasi sebanyak 600 baris. Label kondisi ruangan dibuat berdasarkan aturan ambang suhu, kelembapan, dan cahaya yang ditetapkan untuk proyek.

## Batasan
Hasil evaluasi hanya menggambarkan kinerja model pada dataset simulasi. Pengujian menggunakan data sensor aktual diperlukan sebelum sistem diterapkan di lingkungan nyata.
